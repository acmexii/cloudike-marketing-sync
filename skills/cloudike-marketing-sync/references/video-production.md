# 업그레이드된 앱의 실제 조작 영상과 로컬·Drive 보관

영상에 별도 로고를 표시할 때는 스킬의 `assets/cloudike-logo.png`를 사용하고 비율·색·투명도를 유지한다. 실제 홈페이지에 이미 보이는 로고를 가리거나 중복으로 배치하지 않는다. 출처는 `assets/cloudike-logo-source.json`에 기록되어 있다.

승인된 범위에서 형제 cloudike-service-video 스킬의 제작·검수 지침을 사용한다. 이 스킬의 저장·업로드 대상은 본 문서의 로컬·Drive 규칙을 우선한다. Git·PR의 변경 사항이 실제 배포된 앱 URL에서 보이는지 확인한 뒤 앱 진입→변경 기능의 메뉴/스크롤 이동→실제 기능 조작→화면 반응·결과 확인→확대 강조를 녹화한다. 예전 앱 화면이나 정적 사본에서 변경 기능의 실제 반응을 확인할 수 없으면 녹화·제작을 보류하고 배포 또는 동작 가능한 앱 접근 문제를 알린다. 정지 캡처를 이어 붙인 영상이나 포인터만 합성한 화면을 실제 조작 녹화라고 보고하지 않는다. 지원하는 브라우저·녹화 도구를 사용하고 도구가 없으면 해당 단계의 장애를 기록한다.

마우스는 실제 대상까지 부드럽게 이동→짧은 호버→클릭→실제 반응 확인→결과 체류 순서로 연출한다. 구체적인 이동·스크롤 시간과 좌표 변환은 기존 interaction-motion.md를 따른다. 녹화 포인터가 누락되면 실제 이벤트·좌표 기반 오버레이만 사용하고 중복 커서를 제거한다. 확대 시 화면·커서·클릭 표시를 같은 좌표계로 변환한다.

기본 영상은 한국어 20~40초, 16:9, 1080p, 30fps다. 최초에는 현재 서비스 안내, 이후에는 승인된 변경 설명에 집중한다. Voice ID `1PdAOcPlPTz12RwMyFVp`, 모델 `eleven_multilingual_v2`와 기존 elevenlabs.md 및 `../cloudike-service-video/scripts/elevenlabs_tts.py`를 재사용한다(경로는 skills 디렉터리 기준으로 해석). 환경 변수/기존 DPAPI 키 조회 방식을 유지하며 다른 음성으로 임의 대체하지 않는다. 합성은 사전 승인 후에만 실행한다. 동일 대본 음성은 재사용하고 API 오류는 기존 지침에 따라 중단한다.

실제 음성 타이밍에 확대·강조·자막·포인터 동작을 맞춘다. MP4 전체를 재생·청취하고 제품명 발음, 음절 잘림, 장면 전환, 수치, 클릭 정렬을 확인한다. 원본 녹화·대본·storyboard·alignment·검수 기록을 로컬에 보관한다. 실제 수행하지 않은 검수를 완료라고 쓰지 않는다.

최종 MP4를 프로젝트 로컬 `outputs/cloudike-marketing-sync/videos/<change_id>/`에 생성하고 원본 녹화·대본·음성·정렬·검수 기록도 해당 실행 폴더에 보관한다. 사용자가 프로젝트 내 다른 경로를 지정하면 이를 따른다. 최종 MP4는 승인된 Drive 폴더에 업로드하거나 관리 중인 기존 영상 ID의 새 버전으로 갱신한다. 업로드 후 ID·수정 시각·파일 크기 또는 체크섬과 재생을 확인하고 로컬 경로와 Drive 링크를 함께 보고한다. 업로드 실패는 로컬 제작 성공과 구분해 미완료로 기록한다. 홈페이지에는 PPTX·PDF만 반영하고 영상 파일·플레이어·Drive 영상 링크를 새로 게시하지 않는다. 기존 홈페이지 영상의 삭제는 별도로 승인된 경우에만 수행한다.
